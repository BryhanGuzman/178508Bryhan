OBJETIVO GENERAL

Aplicar conocimientos teóricos en un escenario práctico

Análisis controlado de una máquina vulnerable

El proyecto busca demostrar la capacidad de aplicar conocimientos teóricos de seguridad informática dentro de un entorno práctico y controlado.

A través de un walkthrough se documentan las diferentes fases utilizadas para analizar una máquina virtual vulnerable, identificar posibles vectores de ataque, evaluar vulnerabilidades y comprender su impacto.

Todo el proceso se realiza dentro de un entorno de virtualización aislado diseñado específicamente con fines académicos.

FUNDAMENTOS

Teoría detrás de la práctica

01

Reconocimiento

Fase inicial orientada a recopilar información relevante sobre el sistema objetivo antes de realizar pruebas más específicas.

02

Enumeración

Proceso mediante el cual se obtiene información más detallada sobre servicios, aplicaciones y recursos accesibles.

03

Vulnerabilidad

Debilidad presente en un sistema, servicio o configuración que puede representar un riesgo de seguridad.

04

Explotación

Validación de una vulnerabilidad con el propósito de determinar su impacto dentro de un entorno autorizado.

05

Escalamiento

Evaluación de si el acceso inicial permite obtener privilegios adicionales dentro del sistema.

06

Post-explotación

Fase destinada a analizar el alcance y las consecuencias del acceso conseguido durante la prueba.

APRENDIZAJES

Lo más importante del proyecto

La seguridad informática no consiste únicamente en ejecutar herramientas, sino en comprender qué información proporciona cada etapa y cómo utilizarla para evaluar el riesgo de un sistema.

El proyecto permitió relacionar los conceptos estudiados durante el curso con un escenario práctico, aplicando una metodología ordenada para analizar una máquina vulnerable.

También permitió reforzar la importancia de documentar cada prueba, interpretar los resultados y mantener todas las actividades dentro de un entorno previamente autorizado y controlado.

CONCLUSIÓN

Del conocimiento teórico a una metodología aplicada

Este proyecto permitió integrar los conocimientos adquiridos durante la asignatura en una práctica completa de análisis de seguridad sobre una máquina virtual vulnerable.

El walkthrough muestra la importancia de seguir una metodología ordenada, comprender los resultados obtenidos y documentar correctamente cada etapa para poder explicar tanto el proceso técnico como sus fundamentos.
